# Python 四大容器：列表、元组、字典、集合 共性与个性总结
结合语法、特性、操作、使用场景整理

=============================
一、四大容器 共性
=============================
1. 都属于容器类型，可存放多个数据，支持嵌套使用。
2. 通用内置函数均可用：len() 获取元素个数、max()/min() 求取最值。
3. 均可迭代，支持 for 循环遍历，也支持对应推导式快速生成对象。
4. 元素数据类型灵活，可存放数字、字符串、以及其他容器类型。
5. 都支持成员运算符 in / not in，判断元素是否存在。

=============================
二、四大容器 各自个性（详细区分）
=============================
1. 列表 list
符号：[]
核心特性：
- 有序、可变，支持增、删、改操作
- 元素允许重复，无特殊类型限制
- 通过下标索引、切片访问元素

常用操作与方法：
增：append() 尾部追加、extend() 扩展序列、insert() 指定位置插入
删：del、pop()、remove()、clear()
改：直接通过索引赋值修改元素
其他：count()、index()、reverse()、sort()、copy()

适用场景：有序数据存储、频繁增删改、数据集、普通序列数据。

-------------------------------------------------------------
2. 元组 tuple
符号：()
核心特性：
- 有序、不可变（元素无法修改、新增、删除），只读类型
- 元素允许重复；单元素元组必须加逗号 (50,)，否则识别为普通数值
- 支持下标索引、切片，用法和列表一致

常用操作与规则：
- 不能修改内部元素，仅可使用 del 删除整个元组
- 支持 + 拼接、* 重复运算
- 可用 tuple() 将其他可迭代对象转为元组
- 无增、删、改相关方法

适用场景：保护数据不被篡改、函数多返回值、作为字典的键。

-------------------------------------------------------------
3. 字典 dict
符号：{}
核心特性：
- Python3.7及以上版本保留插入顺序，整体可变
- 存储结构为 键值对 key:value，和普通序列不同
- 键(key)：必须是不可变类型，唯一不重复
- 值(value)：无类型限制，允许重复
- 不支持下标与切片，只能通过键取值

常用操作与方法：
取值：[]（键不存在报错）、get()（安全取值，可设默认值）
增/改：dict[键] = 值、update() 批量更新/合并字典
删：del、pop()、popitem()、clear()
视图方法：keys()、values()、items()
其他：fromkeys()、setdefault()

适用场景：存储映射关系、配置参数、结构化数据、按键快速查找。

-------------------------------------------------------------
4. 集合 set
符号：{}；空集合必须用 set()，{} 代表空字典
核心特性：
- 无序、可变，元素自动去重，不允许重复
- 元素必须是不可变类型，不能存放列表、字典等可变对象
- 无下标、无切片，无法通过位置访问元素

常用操作与方法：
增：add() 添加单个元素、update() 批量添加元素
删：remove()（不存在报错）、discard()（不存在不报错）、pop()（随机删除）
集合运算：union()并集、intersection()交集、difference()差集
          symmetric_difference()对称差集、issubset()子集、issuperset()超集、isdisjoint()判断无交集

适用场景：数据去重、两组数据对比、集合运算、快速成员判断。

=============================
三、特性对比
=============================
特性            列表[]      元组()      字典{}          集合{}
有序性          有序        有序        3.7+有序        无序
可变性          可变        不可变      可变            可变
元素重复        允许重复    允许重复    键不重复/值可重 不允许重复(自动去重)
访问方式        下标/切片   下标/切片   通过键取值      无索引、不能按位置访问
结构            纯元素序列  纯元素序列  键值对结构      纯元素序列
特殊限制        无          单元素加逗号 键不可变       元素不可变

=============================
四、易混点
=============================
1. 大括号{}区分：内部是 k:v 格式 → 字典；只有独立元素 → 集合。
2. 空容器：{} 是空字典，创建空集合必须使用 set()。
3. 可变类型：列表、字典、集合；唯一不可变序列：元组。
4. 索引切片：列表、元组支持；字典、集合不支持切片。
5. 限制规则：字典的键、集合的元素，都不能使用列表、字典等可变类型。
