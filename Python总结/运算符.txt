1.海马运算符
例如:
	a.(n := 10)：将变量 n 赋值为 10，同时返回这个赋值结果。
	b.> 5：检查赋值后的 n 是否大于 5。如果条件为真，则执行接下来的代码块。
	c.print(n)：如果条件为真，打印变量 n 的值（即 10）。
	# 传统写法
	n = 10
	if n > 5:
		print(n)

	# 使用海象运算符
	if (n := 10) > 5:
		print(n)

2.位运算符
&:与；|:或；^:异或；～:非；

3.逻辑运算符
	and；or；not

4.成员运算符(成员包括字符串，列表或元组。)
	in；not in

5.身份运算符(用于比较两个对象的寻出单元)（id()用于获取对象内存地址）
	is:	例如x is y	类似于id(x) == id(y)
	is not:例如 x is not y	类似于id(x)  != id(y)
