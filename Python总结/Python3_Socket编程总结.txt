Python3 Socket 编程精简总结：知识点、代码和输出
这篇总结主要介绍 Socket 的概念、socket() 函数、服务端/客户端编程、Socket 对象方法以及 Python 网络相关模块。下面按核心知识点精简整理。

一、Socket 的概念和作用
	知识点：
		Socket（套接字）是应用程序向网络发出请求或应答网络请求的接口，使主机间或同一台计算机上的进程间能够通讯。
		Python 提供了两个级别的网络服务：
		- 低级别：socket 模块，提供标准的 BSD Sockets API，可访问底层操作系统 Socket 接口的全部方法。
		- 高级别：socketserver 模块，提供服务器中心类，简化网络服务器的开发。
		Socket 通信模型遵循客户端-服务端架构，服务端监听端口等待连接，客户端主动发起连接。

二、socket() 函数
	知识点：
		socket.socket() 用于创建套接字对象，语法为 socket.socket([family[, type[, proto]]])。
		参数说明：
		- family：套接字家族，AF_UNIX（Unix 域套接字，本机进程间通信）或 AF_INET（IPv4 网络通信）。
		- type：套接字类型，SOCK_STREAM（面向连接的 TCP）或 SOCK_DGRAM（无连接的 UDP）。
		- proto：协议号，一般不填，默认为 0。
	代码：
		import socket

		# 创建 TCP 套接字
		tcp_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

		# 创建 UDP 套接字
		udp_socket = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

三、Socket 对象核心方法（服务端）
	知识点：
		s.bind((host, port))：将套接字绑定到指定地址和端口，AF_INET 下以元组 (host, port) 表示。
		s.listen(backlog)：开始 TCP 监听，backlog 指定操作系统可挂起的最大连接数，至少为 1，通常设为 5。
		s.accept()：被动接受 TCP 客户端连接，阻塞等待，返回 (conn, address) 元组，conn 是新的套接字对象用于通信，address 是客户端地址。
	代码：
		import socket

		serversocket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
		host = socket.gethostname()  # 获取本地主机名
		port = 9999

		serversocket.bind((host, port))  # 绑定端口
		serversocket.listen(5)            # 最多 5 个排队连接

		while True:
			clientsocket, addr = serversocket.accept()  # 阻塞等待连接
			print("连接地址: %s" % str(addr))
			msg = '欢迎访问菜鸟教程！' + "\r\n"
			clientsocket.send(msg.encode('utf-8'))
			clientsocket.close()
	输出：
		服务端终端显示：连接地址: ('192.168.0.118', 33397)

四、Socket 对象核心方法（客户端）
	知识点：
		s.connect((host, port))：主动初始化 TCP 连接，地址格式为元组 (hostname, port)，连接失败抛出 socket.error。
		s.connect_ex((host, port))：connect() 的扩展版本，出错时返回错误码而非抛出异常。
		s.recv(bufsize)：接收 TCP 数据，bufsize 指定最大接收字节数，返回字节数据。
		s.send(data)：发送 TCP 数据，返回实际发送的字节数，可能小于数据总长度。
		s.sendall(data)：完整发送 TCP 数据，尝试发送全部数据，成功返回 None，失败抛异常。
		s.close()：关闭套接字，释放资源。
	代码：
		import socket

		s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
		host = socket.gethostname()
		port = 9999

		s.connect((host, port))       # 连接服务端
		msg = s.recv(1024)            # 接收最多 1024 字节
		s.close()
		print(msg.decode('utf-8'))
	输出：
		客户端终端显示：欢迎访问菜鸟教程！

五、UDP 相关方法
	知识点：
		UDP 是无连接协议，不需要 connect() 和 accept()，直接发送和接收数据报。
		s.recvfrom(bufsize)：接收 UDP 数据，返回 (data, address) 元组，data 是数据，address 是发送方地址。
		s.sendto(data, address)：发送 UDP 数据到指定地址，address 为 (ip, port) 元组，返回发送字节数。
	代码：
		import socket

		# UDP 服务端
		udp_server = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
		udp_server.bind(('localhost', 8888))
		data, addr = udp_server.recvfrom(1024)
		print("收到来自 %s 的消息: %s" % (addr, data.decode()))

		# UDP 客户端
		udp_client = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
		udp_client.sendto("Hello UDP".encode('utf-8'), ('localhost', 8888))
	输出：
		服务端显示：收到来自 ('127.0.0.1', 54321) 的消息: Hello UDP

六、Socket 其他常用方法
	知识点：
		s.getpeername()：返回连接套接字的远程地址，返回值是元组 (ipaddr, port)。
		s.getsockname()：返回套接字自身的地址，通常是元组 (ipaddr, port)。
		s.settimeout(timeout)：设置套接字操作超时时间（秒），None 表示无超时。建议在创建套接字后立即设置，因为 connect() 等操作也受超时影响。
		s.gettimeout()：返回当前超时值，未设置返回 None。
		s.setblocking(flag)：flag=False 设为非阻塞模式，此时 recv() 无数据或 send() 无法立即发送会引发 socket.error 异常。
		s.fileno()：返回套接字的文件描述符。
		s.makefile()：创建一个与套接字关联的文件对象，方便用文件读写方式操作 Socket。
		s.setsockopt(level, optname, value)：设置套接字选项，如 SO_REUSEADDR 允许端口重用。
	代码：
		import socket

		s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
		s.settimeout(10)                          # 设置 10 秒超时
		print("超时时间:", s.gettimeout())          # 输出: 10.0

		s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)  # 允许端口重用
		s.bind(('localhost', 8080))

		print("本机地址:", s.getsockname())         # 输出: ('127.0.0.1', 8080)
	输出：
		超时时间: 10.0
		本机地址: ('127.0.0.1', 8080)

七、完整服务端-客户端交互流程
	知识点：
		服务端流程：创建 socket → bind 绑定地址 → listen 监听 → accept 接受连接 → recv/send 收发数据 → close 关闭。
		客户端流程：创建 socket → connect 连接服务端 → send/recv 收发数据 → close 关闭。
		TCP 是面向连接的可靠传输，数据按序到达；UDP 是无连接的，不保证可靠送达但效率更高。
		数据发送前需用 encode() 编码为字节，接收后需用 decode() 解码为字符串。
	代码：
		# server.py —— 服务端
		import socket

		serversocket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
		host = socket.gethostname()
		port = 9999

		serversocket.bind((host, port))
		serversocket.listen(5)

		while True:
			clientsocket, addr = serversocket.accept()
			print("连接地址: %s" % str(addr))
			msg = '欢迎访问菜鸟教程！' + "\r\n"
			clientsocket.send(msg.encode('utf-8'))
			clientsocket.close()

		# client.py —— 客户端
		import socket

		s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
		host = socket.gethostname()
		port = 9999

		s.connect((host, port))
		msg = s.recv(1024)
		s.close()
		print(msg.decode('utf-8'))
	输出：
		# 终端 1 执行 python3 server.py，等待连接
		# 终端 2 执行 python3 client.py
		客户端输出：欢迎访问菜鸟教程！
		服务端输出：连接地址: ('192.168.0.118', 33397)

八、Python 网络编程相关模块
	知识点：
		Python 标准库提供了针对各网络协议的模块，以下是常用协议及对应模块：

		| 协议   | 功能             | 端口 | Python 模块                |
		|--------|------------------|------|----------------------------|
		| HTTP   | 网页访问         | 80   | http.client, urllib        |
		| FTP    | 文件传输         | 20   | ftplib, urllib             |
		| SMTP   | 发送邮件         | 25   | smtplib                    |
		| POP3   | 接收邮件         | 110  | poplib                     |
		| IMAP4  | 获取邮件         | 143  | imaplib                    |
		| NNTP   | 新闻文章阅读     | 119  | nntplib                    |
		| Telnet | 远程命令行       | 23   | telnetlib                  |

		现代 Web 开发中，直接使用 socket 编程的场景较少，更常用的是基于 socket 封装的高层框架（如 Flask、Django）。
		但理解 socket 是掌握网络编程底层原理的关键，也是调试网络问题的基础。

九、Socket 编程核心注意事项
	知识点：
		send() 返回值可能小于待发送数据长度，应使用 sendall() 确保全部发送完成，或循环调用 send()。
		recv() 返回的数据长度可能小于 bufsize，需要根据协议自行判断数据是否接收完整。
		服务端需要循环调用 accept() 以持续接受新连接，每个客户端连接应在新线程或进程中处理以避免阻塞。
		生产环境中应考虑异常处理（try/except），处理连接中断、超时等异常情况。
		数据传输时必须编码（encode）和解码（decode），统一使用 UTF-8 编码。
		服务端关闭时应先关闭客户端套接字，再关闭服务端套接字，避免资源泄漏。
		Python 3 中 socket 传输的是字节（bytes），不再是 Python 2 中的字符串（str），这是常见踩坑点。
