3.字典：字典是另一种可变容器模型，且可存储任意类型对象。字典的每个键值 key=>value 对用冒号 : 分割，每个对之间用逗号(,)分割，整个字典包括在花括号 {} 中 
		a.	d = {key1 : value1, key2 : value2, key3 : value3 }
			键必须是唯一的，但值则不必。值可以取任何数据类型，但键必须是不可变的，如字符串，数字。

		b.访问字典里面的值：如果用字典里没有的键访问数据
			tinydict = {'Name': 'Runoob', 'Age': 7, 'Class': 'First'}
			print ("tinydict['Name']: ", tinydict['Name'])
			print ("tinydict['Age']: ", tinydict['Age'])

		c.删除字典元素
			del tinydict['Name'] # 删除键 'Name'
			tinydict.clear()     # 清空字典
			del tinydict         # 删除字典

		d.字典键的特性
			(1)不允许同一个键出现两次。创建时如果同一个键被赋值两次，后一个值会被记住
			(2)键必须不可变，所以可以用数字，字符串或元组充当，而用列表就不行
				例如:
					tinydict = {['Name']: 'Runoob', 'Age': 7}
					print ("tinydict['Name']: ", tinydict['Name'])

					以上实例输出结果：
					Traceback (most recent call last):
					  File "test.py", line 3, in <module>
						tinydict = {['Name']: 'Runoob', 'Age': 7}
					TypeError: unhashable type: 'list'

		e.字典内置函数&方法
			函数:
				len(dict):计算字典元素个数，即键的总数。
				str(dict):输出字典，可以打印的字符串表示。
					例如:
						>>> tinydict = {'Name': 'Runoob', 'Age': 7, 'Class': 'First'}
						>>> str(tinydict)
						"{'Name': 'Runoob', 'Class': 'First', 'Age': 7}"

			内置方法（d1 = {"name": "张三", "age": 20, "gender": "男"}）:
			(1) dict.fromkeys():用可迭代对象批量生成键，所有键共用同一个初始值。
				例如:
					keys = ["k1", "k2", "k3"]
					new_d = dict.fromkeys(keys, 0)
					print(new_d)   # {'k1': 0, 'k2': 0, 'k3': 0}

					# 不指定val，默认值None
					print(dict.fromkeys(keys))  # {'k1': None, 'k2': None, 'k3': None}

			(2) dict.get(key, default=None):安全取值，键不存在不会报错，返回默认值
				例如:
					print(d1.get("name"))           # 张三
					print(d1.get("height", 175))    # 键不存在，返回175
					print(d1["height"])             # 直接[]取值：KeyError报错

			(3) key in dict:成员运算符，判断键是否存在字典中（不判断值）
				例如：
					print("name" in d1)     # True
					print("张三" in d1)     # False，"张三"是值不是键
					print("email" not in d1)# True

			（4） dict.items():返回 (键,值) 视图对象，可遍历、转列表
				例如:
					item_view = d1.items()
					print(list(item_view))
					# [('name', '张三'), ('age', 20), ('gender', '男')]

					# 常用遍历
					for k, v in d1.items():
						print(k, v)					

			(5) dict.keys():返回所有键的视图对象
					print(list(d1.keys()))  # ['name', 'age', 'gender']

			(6) dict.setdefault(key, default=None):和get相似，但键不存在时自动插入该键
				例如:
					# 键存在：直接返回原值，不修改字典
					print(d1.setdefault("age", 99))  # 20
					# 键不存在：新增键值对，返回default
					print(d1.setdefault("height", 178)) # 178
					print(d1) # 新增了height:178

			(7) dict.values():返回所有值的视图对象*******dict.keys()同理
				例如:
					print(list(d1.values()))
					# ['张三', 21, '男', 178, 'test@qq.com']

			(8) dict.update(dict2):批量合并 / 更新键值对，重复键覆盖原值
				例如:
					d2 = {"age": 21, "email": "test@qq.com"}
					d1.update(d2)
					print(d1)
					# age被更新，新增email

				***
					写法 1：传入另一个字典（你之前见过）
					python
					运行
					d1.update({"age":25, "email":"aaa@qq.com"})
					批量合并字典，重复键直接覆盖旧值。
					写法 2：关键字参数 k=v（就是你问的这种）
					python
					运行
					d1.update(phone="123456", address="南京")
					不用写大括号、不用引号包键名
					可以一次性传多组键值

					

			(9) dict.pop(key[, default]):删除指定键，返回被删除的值；键不存在且没给 default 则报错
				例如:
					val = d1.pop("gender")
					print(val)      # 男
					print(d1)       # gender已移除

					# 给默认值，不存在不报错
					res = d1.pop("xxx", "不存在该键")
					print(res)

			(10) dict.popitem():删除并返回字典最后插入的一组键值对（Python3.7 + 字典有序），空字典调用报错
				例如:
					last_item = d1.popitem()
					print(last_item)    # ('email', 'test@qq.com')
					print(d1)
