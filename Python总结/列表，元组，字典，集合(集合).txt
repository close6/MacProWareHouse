4.集合:集合（set）是一个无序的不重复元素序列。集合中的元素不会重复，并且可以进行交集、并集、差集等常见的集合操作。可以使用大括号 { } 创建集合，元素之间用逗号 , 分隔， 或者也可以使用 set() 函数创建集合。
		a.简单实例：
				set1 = {1, 2, 3, 4}            # 直接使用大括号创建集合
				set2 = set([4, 5, 6, 7])      # 使用 set() 函数从列表创建集合
			注意：创建一个空集合必须用 set() 而不是 { }，因为 { } 是用来创建一个空字典。	

		b.添加元素(add(),update())
				例一:add()
					>>> thisset = set(("Google", "Runoob", "Taobao"))
					>>> thisset.add("Facebook")
					>>> print(thisset)
					{'Taobao', 'Facebook', 'Google', 'Runoob'}
				例二:update()可以添加元素，且参数可以是列表，元组，字典等,x 可以有多个，用逗号分开
					>>> thisset = set(("Google", "Runoob", "Taobao"))
					>>> thisset.update({1,3})
					>>> print(thisset)
					{1, 3, 'Google', 'Taobao', 'Runoob'}
					>>> thisset.update([1,4],[5,6])  
					>>> print(thisset)
					{1, 3, 4, 5, 6, 'Google', 'Taobao', 'Runoob'}

		c.移除元素(remove(),discard(),pop())
				例一:remove()将元素 x 从集合 s 中移除，如果元素不存在，则会发生错误。
					>>> thisset = set(("Google", "Runoob", "Taobao"))
					>>> thisset.remove("Taobao")
					>>> print(thisset)
					{'Google', 'Runoob'}
					>>> thisset.remove("Facebook")   # 不存在会发生错误
					Traceback (most recent call last):
					  File "<stdin>", line 1, in <module>
					KeyError: 'Facebook'
				例二:discard()也是移除集合中的元素，且如果元素不存在，不会发生错误。
					>>> thisset = set(("Google", "Runoob", "Taobao"))
					>>> thisset.discard("Facebook")  # 不存在不会发生错误
					>>> print(thisset)
					{'Taobao', 'Google', 'Runoob'}
				例三:pop()随机删除集合中的一个元素,多次执行测试结果都不一样。
					thisset = set(("Google", "Runoob", "Taobao", "Facebook"))
					x = thisset.pop()
					print(x)

		d.集合内置方法：
				(1)difference():返回一个新集合，该集合包含所有在第一个集合中，但不在其他传入集合中的元素。
					例如:
						set1 = {1, 2, 3, 4}
						set2 = {3, 4, 5, 6}
						result = set1.difference(set2)
						print(result)  
						输出:{1, 2}
				(2)intersection():返回一个新集合，该集合包含所有同时存在于所有传入集合中的元素。
					例如:
						set1 = {1, 2, 3, 4}
						set2 = {3, 4, 5, 6}
						result = set1.intersection(set2)
						print(result)  
						输出：{3, 4}
				(3)isdisjoint():检查两个集合是否没有共同元素，有则返回 False，没有则返回 True。
					例如:
						set1 = {1, 2, 3}
						set2 = {4, 5, 6}
						print(set1.isdisjoint(set2))  
						set3 = {3, 4, 5}
						print(set1.isdisjoint(set3))  
						输出:True和False
				(4)issubset():检查当前集合是否是另一个集合的子集，即当前集合的所有元素都在另一个集合中。
					例如:
						set1 = {1, 2}
						set2 = {1, 2, 3}
						print(set1.issubset(set2))  
						set3 = {3, 4}
						print(set1.issubset(set3))  
						输出:True和False
				(5)issuperset():检查另一个集合是否是当前集合的子集，即另一个集合的所有元素都在当前集合中。
				(6)symmetric_difference():返回一个新集合，该集合包含所有只在其中一个集合中出现，而不在两个集合中同时出现的元素。
					例如:
						set1 = {1, 2, 3}和set2 = {2, 3, 4}，输出:{1, 4}
				(7)union():返回一个新集合，该集合包含所有在所有传入集合中出现的元素，重复元素只会出现一次。
