一、函数基础
定义:
函数是一段可重复调用、实现单一功能的代码块，分为内置函数（print、len 等）、自定义函数（def 定义）。
作用:
代码复用、程序模块化，减少重复代码。
定义语法:
def 函数名 (参数列表):
"""文档字符串，用于说明函数功能"""
函数体（必须缩进）
return [表达式]
语法规则
(1) def 是定义函数关键字；
(2) 括号存放形参，无参数括号也不能省略；
(3) 冒号开启代码段，内部代码统一缩进；
(4) return 用于结束函数并返回数据，无 return 默认返回 None；
(5) 调用方式：函数名 (实参)。


二、参数传递机制
Python 不分值传递 / 引用传递，按对象可变特性区分：
不可变对象：数字、字符串、元组:
		函数内修改形参，会创建新对象，外部实参不受影响，可用 id () 查看内存地址验证。
可变对象：列表、字典:
		传递对象引用，函数内增删修改会直接改变外部原始数据。
概念区分:
形参：定义函数时括号内的变量；
实参：调用函数时传入的真实数据。


三、5 类函数参数
必需位置参数
		调用时参数数量、顺序必须和定义完全一致，缺参、顺序错乱直接报错。
关键字参数
		调用使用 形参 = 值 传参，不受顺序限制；位置参数必须写在关键字参数前面。
			示例：printinfo (age=50, name="runoob")
默认参数
		定义时给形参赋值，调用不传该参数则自动使用默认值。
			示例：def printinfo (name, age=35):
不定长参数
		(1) *args：接收多余位置参数，打包成元组；
		(2) *kwargs：接收多余关键字参数，打包为字典；
		(3) 单独：后面的参数必须用关键字传入。
			示例：def f (a,b,,c):
Python3.8 新增强制位置参数 /
		/ 左侧只能位置传参，* 右侧只能关键字传参。
		示例：def f (a, b, /, c, d, *, e, f):


四、return 返回值规则
执行 return 后函数立即终止，后续代码不运行；
无 return、仅写 return，统一返回 None；
同时返回多个值，会自动封装为元组。


五、匿名函数 lambda
		语法：lambda 参数列表：单行表达式
		特点
		(1) 无需 def 定义，无函数名；
		(2) 仅支持单行表达式，不能写复杂代码块；
		(3) 拥有独立命名空间，无法直接读取外部全局变量；
		(4) 常搭配 map、sorted 排序使用，可作为返回值实现闭包。
			示例:
				单参数:
				x = lambda a : a + 10
				双参数求和:
				sum_func = lambda a,b: a+b
				闭包用法:
				def myfunc(n):
					return lambda a : a * n

				mydoubler = myfunc(2)


六、变量作用域（全局 / 局部）
函数内可以直接读取全局变量；
函数内给全局变量赋值，Python 判定为局部变量，先读取再赋值会抛 UnboundLocalError；
global 关键字：声明变量为全局，可在函数内部修改全局变量；
嵌套内部函数修改外层变量使用 nonlocal。


七、递归函数
函数内部调用自身，必须设置终止条件，否则无限递归报错。
示例：
def Foo (x):
		if (x==1):
		return 1
		else:
		return x+Foo (x-1)

print (Foo (4)) # 输出 10


八、装饰器（高阶函数进阶）
作用：不修改原函数代码，给函数新增功能；
本质：高阶函数 + 闭包，@是装饰器语法糖；
完整示例
def log(pr):
    # 内层闭包函数wrapper
    def wrapper():
        print("**********")
        # 执行原始函数pr
        return pr()
    # 返回内层函数对象（不是调用wrapper()）
    return wrapper

# 语法糖写法，等价于 pr = log(pr)
@log
def pr():
    print("我是小小洋")

# 调用
pr()


九、高阶函数
定义：可以将函数作为参数传入另一个函数；
常用 map：批量处理序列每一个元素。
示例：
numbers = [1, 3, 6]
newNumbers = tuple (map (lambda x: x , numbers))
print (newNumbers) # (1, 3, 6)


十、习题核心考点
无 return 的函数返回 None；
* 不定长参数接收的数据类型为元组；
lambda 仅支持单行表达式；
装饰器无侵入拓展函数功能；
递归必须设置终止条件；
/ 代表强制位置参数，* 代表强制关键字参数；
列表、字典传入函数，内部修改会影响外部原数据；
修改全局变量需加 global 关键字。
