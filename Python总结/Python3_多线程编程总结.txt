Python3 多线程编程精简总结：知识点、代码和输出
这篇总结主要介绍 Python3 多线程的概念、两种创建方式（函数式和类继承式）、线程同步（Lock）以及线程优先级队列（Queue）。下面按核心知识点精简整理。

一、多线程的概念和作用
	知识点：
		多线程类似于同时执行多个不同程序，每个独立线程有入口、顺序执行序列和出口，但不能独立执行，必须依附于应用程序。
		每个线程有自己的 CPU 寄存器上下文，线程可被抢占（中断）或暂时搁置（睡眠/退让）。
		多线程的优点：后台处理耗时任务、提升用户界面响应、加快程序运行速度、在等待任务（I/O、网络）时释放资源。
		线程分为内核线程（操作系统创建和撤销）和用户线程（用户程序中实现）。
		Python3 中常用线程模块为 _thread（低级别、已废弃）和 threading（推荐使用）。
		重要：由于 GIL（全局解释器锁）的存在，Python3 多线程在同一时刻只有一个线程在执行 CPU 密集型任务，多线程主要对 I/O 密集型任务有提升。

二、使用 _thread 模块创建线程（函数式）
	知识点：
		调用 _thread.start_new_thread(function, args[, kwargs]) 产生新线程。
		function 是线程函数，args 是传递给函数的参数（必须为元组），kwargs 是可选关键字参数。
		此方式较原始，无法方便地获取线程状态或等待线程结束，一般只用于简单场景。
		主线程需要一个无限循环（如 while 1: pass）保持运行，否则程序会直接退出。
	代码：
		#!/usr/bin/python3
		import _thread
		import time

		def print_time(threadName, delay):
			count = 0
			while count < 5:
				time.sleep(delay)
				count += 1
				print("%s: %s" % (threadName, time.ctime(time.time())))

		# 创建两个线程
		try:
			_thread.start_new_thread(print_time, ("Thread-1", 2,))
			_thread.start_new_thread(print_time, ("Thread-2", 4,))
		except:
			print("Error: 无法启动线程")

		while 1:
			pass
	输出：
		Thread-1: Wed Jan  5 17:38:08 2022
		Thread-2: Wed Jan  5 17:38:10 2022
		Thread-1: Wed Jan  5 17:38:10 2022
		Thread-1: Wed Jan  5 17:38:12 2022
		Thread-2: Wed Jan  5 17:38:14 2022
		...（Thread-1 每 2 秒输出一次，Thread-2 每 4 秒输出一次，交替运行）

三、threading 模块的核心方法
	知识点：
		threading 模块是 Python3 中推荐的线程模块，包含 _thread 的所有功能并提供更多高级接口。
		threading.current_thread()：返回当前线程变量。
		threading.enumerate()：返回正在运行的线程列表（启动后、结束前）。
		threading.active_count()：返回正在运行的线程数量，等同于 len(threading.enumerate())。
		threading.Thread(target, args=(), kwargs={}, daemon=None)：创建线程实例。
	代码：
		import threading

		print("当前线程:", threading.current_thread().name)
		print("活跃线程数:", threading.active_count())
		print("线程列表:", threading.enumerate())
	输出：
		当前线程: MainThread
		活跃线程数: 1
		线程列表: [<_MainThread(MainThread, started 12345)>]

四、threading.Thread 类的核心方法
	知识点：
		__init__(self, group=None, target=None, name=None, args=(), kwargs={}, daemon=None)：初始化线程对象。
			- target：线程执行的目标函数
			- name：线程名称
			- args：目标函数的位置参数（元组）
			- kwargs：目标函数的关键字参数（字典）
			- daemon：是否为守护线程（True 时主线程退出则该线程也随之退出）
		start()：启动线程，内部调用 run() 方法。
		run()：定义线程执行的代码，可重写此方法。
		join(timeout=None)：等待线程终止，默认阻塞直到线程结束。
		is_alive()：返回线程是否在运行（已启动且未终止）。
		getName() / setName(name)：获取/设置线程名称。
		ident 属性：线程的唯一标识符。
		daemon 属性：守护线程标志，主线程结束后守护线程自动退出。
	代码：
		import threading
		import time

		def print_numbers():
			for i in range(5):
				time.sleep(1)
				print(i)

		# 创建线程
		thread = threading.Thread(target=print_numbers)

		# 启动线程
		thread.start()

		# 等待线程结束
		thread.join()
	输出：
		0
		1
		2
		3
		4

五、通过继承 Thread 类创建线程
	知识点：
		通过继承 threading.Thread 创建子类，重写 __init__() 和 run() 方法。
		__init__() 中调用父类的 __init__()，并设置自定义属性（如线程 ID、名称、延迟等）。
		run() 中编写线程要执行的具体逻辑。
		实例化子类后调用 start() 启动线程，内部会自动调用 run()。
		使用 join() 等待所有线程完成后，主线程再退出。
	代码：
		#!/usr/bin/python3
		import threading
		import time

		exitFlag = 0

		class myThread(threading.Thread):
			def __init__(self, threadID, name, delay):
				threading.Thread.__init__(self)
				self.threadID = threadID
				self.name = name
				self.delay = delay
			def run(self):
				print("开始线程：" + self.name)
				print_time(self.name, self.delay, 5)
				print("退出线程：" + self.name)

		def print_time(threadName, delay, counter):
			while counter:
				if exitFlag:
					threadName.exit()
				time.sleep(delay)
				print("%s: %s" % (threadName, time.ctime(time.time())))
				counter -= 1

		thread1 = myThread(1, "Thread-1", 1)
		thread2 = myThread(2, "Thread-2", 2)

		thread1.start()
		thread2.start()
		thread1.join()
		thread2.join()
		print("退出主线程")
	输出：
		开始线程：Thread-1
		开始线程：Thread-2
		Thread-1: Wed Jan  5 17:34:54 2022
		Thread-2: Wed Jan  5 17:34:55 2022
		Thread-1: Wed Jan  5 17:34:55 2022
		Thread-1: Wed Jan  5 17:34:56 2022
		Thread-2: Wed Jan  5 17:34:57 2022
		...（两个线程交替输出，Thread-1 每 1 秒，Thread-2 每 2 秒）
		退出线程：Thread-1
		退出线程：Thread-2
		退出主线程

六、线程同步（Lock 锁）
	知识点：
		多个线程同时修改共享数据时，可能出现不可预料的结果（数据不同步）。
		例如：线程 A 从后往前改列表为 1，线程 B 同时从前往后打印，可能输出一半 0 一半 1。
		使用 threading.Lock() 创建锁，通过 acquire() 获取锁（如已被占用则阻塞等待），通过 release() 释放锁。
		锁有两种状态：锁定和未锁定。每次只允许一个线程操作共享数据，保证数据一致性。
		注意事项：务必保证 acquire() 和 release() 成对出现，推荐使用 try/finally 确保锁一定会被释放。
	代码：
		#!/usr/bin/python3
		import threading
		import time

		class myThread(threading.Thread):
			def __init__(self, threadID, name, delay):
				threading.Thread.__init__(self)
				self.threadID = threadID
				self.name = name
				self.delay = delay
			def run(self):
				print("开启线程： " + self.name)
				threadLock.acquire()          # 获取锁
				print_time(self.name, self.delay, 3)
				threadLock.release()          # 释放锁

		def print_time(threadName, delay, counter):
			while counter:
				time.sleep(delay)
				print("%s: %s" % (threadName, time.ctime(time.time())))
				counter -= 1

		threadLock = threading.Lock()
		threads = []

		thread1 = myThread(1, "Thread-1", 1)
		thread2 = myThread(2, "Thread-2", 2)

		thread1.start()
		thread2.start()
		threads.append(thread1)
		threads.append(thread2)

		for t in threads:
			t.join()
		print("退出主线程")
	输出：
		开启线程： Thread-1
		开启线程： Thread-2
		Thread-1: Wed Jan  5 17:36:50 2022
		Thread-1: Wed Jan  5 17:36:51 2022
		Thread-1: Wed Jan  5 17:36:52 2022
		Thread-2: Wed Jan  5 17:36:54 2022
		Thread-2: Wed Jan  5 17:36:56 2022
		Thread-2: Wed Jan  5 17:36:58 2022
		退出主线程
		（注意：加锁后 Thread-2 必须等 Thread-1 完全执行完毕才开始，不会交替输出）

七、线程优先级队列（Queue 模块）
	知识点：
		Python 的 queue 模块提供了同步的、线程安全的队列类：
		- Queue：FIFO（先进先出）队列
		- LifoQueue：LIFO（后进先出）队列
		- PriorityQueue：优先级队列
		队列内部实现了锁原语，可在多线程中安全使用，是实现线程间同步的推荐方式。
		Queue 模块常用方法：
		- qsize()：返回队列大小
		- empty()：队列为空返回 True
		- full()：队列满返回 True（与 maxsize 对应）
		- get([block[, timeout]])：获取队列元素，可设置阻塞和超时
		- get_nowait()：等同于 get(False)，非阻塞获取
		- put(item)：写入队列，可设置阻塞和超时
		- put_nowait(item)：等同于 put(item, False)，非阻塞写入
		- task_done()：向队列发送任务完成信号
		- join()：等待队列为空后再执行后续操作
	代码：
		#!/usr/bin/python3
		import queue
		import threading
		import time

		exitFlag = 0

		class myThread(threading.Thread):
			def __init__(self, threadID, name, q):
				threading.Thread.__init__(self)
				self.threadID = threadID
				self.name = name
				self.q = q
			def run(self):
				print("开启线程：" + self.name)
				process_data(self.name, self.q)
				print("退出线程：" + self.name)

		def process_data(threadName, q):
			while not exitFlag:
				queueLock.acquire()
				if not workQueue.empty():
					data = q.get()
					queueLock.release()
					print("%s processing %s" % (threadName, data))
				else:
					queueLock.release()
				time.sleep(1)

		threadList = ["Thread-1", "Thread-2", "Thread-3"]
		nameList = ["One", "Two", "Three", "Four", "Five"]
		queueLock = threading.Lock()
		workQueue = queue.Queue(10)
		threads = []
		threadID = 1

		for tName in threadList:
			thread = myThread(threadID, tName, workQueue)
			thread.start()
			threads.append(thread)
			threadID += 1

		queueLock.acquire()
		for word in nameList:
			workQueue.put(word)
		queueLock.release()

		while not workQueue.empty():
			pass

		exitFlag = 1

		for t in threads:
			t.join()
		print("退出主线程")
	输出：
		开启线程：Thread-1
		开启线程：Thread-2
		开启线程：Thread-3
		Thread-3 processing One
		Thread-1 processing Two
		Thread-2 processing Three
		Thread-3 processing Four
		Thread-1 processing Five
		退出线程：Thread-3
		退出线程：Thread-2
		退出线程：Thread-1
		退出主线程

八、多线程核心注意事项
	知识点：
		Python3 中不要再使用 thread 模块（已废弃），使用 _thread 仅用于简单场景，推荐始终使用 threading。
		由于 GIL 的存在，Python 多线程不适合 CPU 密集型任务（如大量计算），应使用 multiprocessing 多进程。
		多线程适合 I/O 密集型任务（网络请求、文件读写、数据库操作等），可以在等待 I/O 时切换到其他线程。
		使用 Lock 时必须确保 acquire() 和 release() 成对出现，否则可能导致死锁。
		推荐使用 with lock: 语法（上下文管理器）自动管理锁的获取和释放，避免忘记 release。
		daemon=True 的守护线程会在主线程结束时自动退出，适合后台任务；但守护线程中的资源可能无法正常释放。
		线程间通信推荐使用 Queue 队列，比共享变量+锁更安全、更简洁。
		避免在多线程中直接修改全局变量，如必须修改则一定要加锁保护。
