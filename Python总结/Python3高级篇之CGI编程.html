Python 3 的 CGI（Common Gateway Interface）编程允许你在 Web 服务器上运行 Python 脚本，生成动态网页内容。虽然现在大多数现代 Web 开发使用的是框架如 Flask、Django 等，但学习 CGI 对理解 Web 请求/响应模型和早期 Web 技术仍然很有帮助。

一、什么是 CGI？

CGI 是一种标准接口协议，Web 服务器通过它来调用外部程序（比如 Python 脚本），处理客户端请求并返回动态内容。

二、Python3 CGI 编程基本步骤

2.1 前提条件：

  • 安装了 Python 3
  • 安装了一个支持 CGI 的 Web 服务器（如 Apache 或使用 Python 自带的简易服务器）
  • 具备基本 HTML 和 Python 编程知识

2.2 示例：Hello World CGI 脚本（Python 3）

创建一个名为 hello.py 的文件，并写入以下代码：

#!/usr/bin/env python3

print("Content-Type: text/html")    # HTTP 头部
print()                             # 空行，必须有！
print("<html>")
print("<head><title>Hello, CGI!</title></head>")
print("<body>")
print("<h1>Hello, World from Python 3 CGI!</h1>")
print("</body>")
print("</html>")

⚠️ 注意事项：

  • 第一行是 shebang 行，指定解释器路径，可能需要根据系统环境调整。
  • 必须先打印 Content-Type 头，然后是一个空行。
  • 如果缺少空行或格式错误，浏览器会显示“500 Internal Server Error”。

三、运行 CGI 脚本的方法

3.1 方法一：使用 Python 内置的简单 CGI 服务器（测试用）

在终端中执行以下命令启动服务器：

cd /path/to/your/cgi/scripts
python3 -m http.server --cgi 8000

访问地址：

http://localhost:8000/cgi-bin/hello.py

💡 说明：

  • 该服务器将 cgi-bin 子目录中的 .py 文件当作 CGI 脚本执行。
  • 仅用于本地开发和测试，不适合生产环境。

3.2 方法二：使用 Apache 配置 CGI（适用于 Linux）

  1. 将脚本放入 Apache 的 CGI 目录（例如 /usr/lib/cgi-bin/）

  2. 设置可执行权限：

chmod +x hello.py
  1. 启动 Apache 并访问：
http://localhost/cgi-bin/hello.py

确保 Apache 的配置中启用了 CGI 模块，通常是这样设置的：

ScriptAlias /cgi-bin/ /usr/lib/cgi-bin/
<Directory "/usr/lib/cgi-bin">
    AllowOverride None
    Options +ExecCGI -MultiViews +SymLinksIfOwnerMatch
    Require all granted
</Directory>

四、获取用户输入（GET & POST）

使用 Python 标准库 cgi 可以方便地获取表单数据。

4.1 示例：接收 POST 表单数据

#!/usr/bin/env python3

import cgi

form = cgi.FieldStorage()
name = form.getvalue('name', 'Guest')

print("Content-Type: text/html")
print()
print(f"<html><body><h1>Hello, {
              name}!</h1></body></html>")

HTML 表单示例：

<form action="http://localhost:8000/cgi-bin/greet.py" method="post">
  Name: <input type="text" name="name">
  <input type="submit" value="Submit">
</form>

4.2 使用 GET 方法传递参数

URL 示例：

http://localhost/cgi-bin/greet.py?name=Tom

修改脚本如下：

#!/usr/bin/env python3

import cgi

form = cgi.FieldStorage()
name = form.getvalue('name', 'Guest')

print("Content-Type: text/html")
print()
print(f"<html><body><h1>Hello, {
              name}!</h1></body></html>")

五、安全注意事项

CGI 脚本存在潜在的安全风险，尤其当它直接与用户输入交互时：

  • 验证输入：防止注入攻击
  • 避免拼接命令：不要将用户输入直接插入到 shell 命令或数据库查询中
  • 限制权限：CGI 脚本应以最小权限运行
  • 日志记录：记录异常行为，便于排查问题
